DeliveryDash is a text-based adventure game with a simple interactive GUI.
The game is based on a delivery worker who has to deliver food from a takeaway to a customer's house. He will face challenges
along the way and will have to figure out how to get to the destination in the least amount of time possible in order to keep 
the customer's food fresh.

Prerequisites
Java JDK 17+
Maven 3.8+ 

To build the executable jar run `mvn clean package` from the project root
You will then find the executable jar at target/deliverydash.jar
Run `java -jar target/deliverydash.jar` from the project root
